StyleMatch

A transparent writing-style matcher: top authors, decomposed style and topic scores, and readable evidence for every result.

Within-language: 70% style / 30% topic Cross-language: reduced confidence

M1 is a static UI prototype. It demonstrates the required interface and score decomposition; production scoring still needs the separate style and topic model channels described in Claude.md.

Run a passage to see a ranked top-3 match with style/topic sub-scores and explanations.
