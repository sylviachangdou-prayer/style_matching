Abstract

StyleMatch is an open-set, multilingual author-style retrieval system: it treats attribution as profile ranking plus verification rather than closed-set classification, and it may return no match. A query passage is encoded once per channel by two physically separate models — a contrastively fine-tuned multilingual authorship-representation encoder for style, selected over an mStyleDistance baseline on identical source-heldout comparisons, and a multilingual E5 encoder for topic — and compared against precomputed author centroids and source prototypes by exact inner product. Style and topic similarities are always reported separately; the composite affinity is a declared product rule, and all scores are uncalibrated cosine values used for ranking, never probabilities. Profiles are built solely from original-language primary texts — translations are excluded because translationese distorts syntax, punctuation, and register — and cross-language retrieval is served as a reduced-confidence mode ranked per target language, since raw multilingual cosines are not comparable across language pairs.
